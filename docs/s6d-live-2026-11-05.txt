1. Entry check (wd24adv_core.c wd24_entry_check, WD24_PH_LOAD):
   - Reads SR06 (PR20); at load must be 0x0F ("locked value").
   - Then port_seq_unlocked() (wd24adv_port.c): write 3C4 index 0x11, read
     index — 0x01 => locked (return 0), 0x11 => unlocked (return 1).
   - Refuse -ENODEV if unl != 0. Message "SR06 read 01 expected 00" prints
     the *width-test result* (got=unl want=0), NOT the SR06 data register.
   - Live fail: SR06 data must have been 0x0F (else earlier message), width=1
     unlocked. Index writes 12, data writes 0 — fail-safe as designed.
   - Host test_vga #33: SR06 latch unlocked at entry → -ENODEV, 0 data writes.

   When 01 (unlocked) is "valid": mid S6/S6b/S6c after deliberate unlock to
   4Fh ((BIOS&EFh)|48h); SR06 bits 3:0 still read 0Fh. Not valid at *load*
   entry — load requires locked, then save_ext unlocks, plan ends with relock.

2. vs S6/S6b/S6c and boot context:
