## Stop rules

One phase per approval. A pass does not start the next phase. A failure
stops the series. Do not retry a failed open or a failed PUT. Do not add
`s6d_cmap=1` during phase 1. Do not call `FBIOPUTCMAP` during phase 2.

Before any command: a person is present, `/proc/fb` is empty, and
`sha256sum` of the file about to be loaded matches the hash named for
that phase. The candidate name inside the module is still `wd24adv`.
Do not overwrite the baseline file with it.

## Phase 1 — default off — one pass recorded

The trial is recorded in `docs/s6d-live-2026-11-05.txt`. It does not
authorize phase 2. Script `docs/s6d-cmap-phase1-run.sh`.
Artifact `/opt/cursor/artifacts/wd24x-cmap-phase1-run.sh`.
Module path `/tmp/wd24adv-cmap-92591b1e.ko`.
The insmod line omits `s6d_cmap`. The baseline file
`/tmp/wd24adv-pr14.ko` is not the module loaded and is not written.

The candidate proc keeps the baseline lines and adds
`cmap_param %d published %d frozen %d`. Before the glyph client the
script requires `cmap_param 0 published 0`. `s6d_arm` clears `frozen`.
`s6d_fb_release` and `s6d_stop` set `frozen`, including when the
parameter is off, so the expiry gate does not require `frozen 0`.
It still requires `armed 0`, `fb_reg 0`, `thrash 0 latched 0`, and
`cmap_param 0 published 0`.

Expect the same text-restore shape as the baseline glyph pass:
`wd24adv live: trial expiry -> 0`, `readback mismatches 0;`,
`in_text 1;`, empty `/proc/fb`, VGA+ bind 1, `RM=0`. The glyph line
is `WD24X-GLYPH shadow 640x480x8 marks 5 match 5 ctrl 1` with `CL=0`.
`FBIOGETCMAP` stays `-EINVAL` because this phase does not publish a
colormap. It does not prove colours.

Stop after rmmod. Do not continue.
