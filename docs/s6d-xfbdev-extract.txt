CONFIG_FEATURE_SEAMLESS_GZ=y so tar -z reads gzip. No gzip compressor

The archive magic is ustar with the GNU spacing. BusyBox accepts that

ELF: 32-bit LSB pie, Intel 80386 (the ELF machine field for IA-32),

Two f3 90 pause encodings are present. The extract below ran to
completion under qemu-i386 8.2.2 -cpu 486, so that path did not SIGILL.

The binary reads argv[1] as the applet only when its own file name
starts with busybox. That is upstream BusyBox, not a new parser.
