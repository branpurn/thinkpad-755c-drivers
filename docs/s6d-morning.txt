Morning hardware batch. Offline notes only. The 755C was off when
this was written. Do not load a module built in the cloud VM: that
tree stamps vermagic `6.18.57` without `-tc755x`.

Build the module from this commit on the floppy tree so vermagic is
`6.18.57-tc755x mod_unload 486`. It must include the cache change
`d2a5e90` and the 13h aperture map. Pin the new `.ko` sha before the
first insmod. `9a5fc5a4` is the module from `370075d`. Its desktop
run passed glyph, xcmp, and the cache check, then stopped at
`session` because the script required `frozen 1` while X still held
`/dev/fb0`. That module does not have the aperture map. Do not reuse
it for this batch.

Build Doom with the i486 musl compiler, pin `e257a095`, and

```
WD24X_DOOM_FAST=all
```

Leave `WD24X_DOOM_DETAIL` unset. `low` changes the picture. Pin
`wd24x-doom` before the first run. `FAST=all` is
`-fomit-frame-pointer`, the direct 320x200 buffer, and the unrolled
column and span. It does not turn on either aperture path. One
binary runs all three Doom steps.

Order, one script at a time, each with its own insmod and rmmod.
Do not start the next until the previous done line is on the serial
log.

1. `sh /tmp/s6d-doom-run.sh timedemo13h`
   Script `docs/s6d-doom-run.sh`
   sha256 `f545a5ed864c76edd1019c3a25118dde9504fff367fe791c832df2de14afa0be`
   13460 bytes.
   Pass: Doom's `timed N gametics in N realtics (N fps)`,
   `WD24X-DOOM-FPS gametics N realtics N fps_x100 N`,
   `WD24X-DOOM blit direct 64000`, `present switches 0`,
   `WD24X-DOOM-RUN restore mismatches 0`, `WD24X-DOOM-RUN done`.
   Exit 255 with that gametics line is success. The last measured
   line, before these flags, was `timed 5026 gametics in 14978
   realtics (11.744559 fps)` (`fps_x100` 1174).

2. `sh /tmp/s6d-doom-run.sh timedemo13hmap`
   Same script and the same Doom binary. The module is
   `mode=320x200-8 present_mode=13h`. Doom sets
   `WD24X_DOOM_FB=aperture` and maps `0xA0000` for 65536 bytes.
   The frame is the first 64000. The other 1536 bytes are inside
   `A0000-AFFFF` and are not the frame. The map writes no VGA
   register and does not call SETWIN. Close does not run the
   dual-window end. Text restore is still the trial / rmmod path.
   Pass: `WD24X-DOOM fb mmap 320 200 aperture`,
   `WD24X-DOOM blit aperture 64000`, `faults 0 switches 0`,
   `mode 13h`, the gametics line, `restore mismatches 0`,
   `WD24X-DOOM-RUN done`. A slower gametics line than step 1 is
   still a pass. Each column store is an uncached write.

3. `sh /tmp/s6d-doom-run.sh timedemo13hcopy`
   Same script and the same Doom binary. Doom sets
   `WD24X_DOOM_FB=aperturecopy`. The renderer stays in the cached
   malloc. Each frame is one 64000-byte dword copy into the mapped
   window. No present ioctl. Pass: `WD24X-DOOM fb mmap 320 200
   aperturecopy`, `WD24X-DOOM blit aperturecopy 64000`,
   `faults 0 switches 0`, `mode 13h`, the gametics line,
   `restore mismatches 0`, `WD24X-DOOM-RUN done`.
